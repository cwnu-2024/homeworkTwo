# Expense Tracker

A complete mobile-friendly web expense tracker with local browser storage.

## Features

- Dashboard summaries for daily, weekly, and monthly income and expenses.
- Add screen for expense or income transactions.
- Budget screen with monthly limits by category and exceeded-limit alerts.
- Bottom navigation for Home, Add, and Budget.
- Clear All reset action.
- Required-field, numeric-range, and date validation.
- Local persistence through `localStorage`.

## Run

Open `index.html` in a browser, or serve the folder with any static web server.

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.
