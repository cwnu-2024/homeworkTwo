# SpendWise Mobile App

**App Idea:** 
A simple personal expense recorder that helps users keep track of their daily spending. Users can input item names, costs, and categories to view a summary of their habits.

**Technology:** 
- Mobile Web (HTML5, CSS3, JavaScript)
- Storage: LocalStorage API

**Screens:**
1. **Home:** Introduction and navigation.
2. **Add Expense:** Form with validation.
3. **Summary:** List of all entered data.

**Validation Rules:**
- Item Name: Required, Minimum 3 characters.
- Amount: Required, Must be a positive number.
- Date: Required.
