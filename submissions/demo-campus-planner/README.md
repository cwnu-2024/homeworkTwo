# Campus Plan

Campus Plan is a small mobile web app for creating a simple student day plan. It lets a user enter an activity, date, time block, food budget, notes, and reminder choice, then shows the saved plan on a summary screen.

## Technology

- HTML
- CSS
- JavaScript
- Browser localStorage

## How to Run

Open `index.html` in a browser. No installation is required.

## Requirements Completed

- Three screens: Home, Plan, Summary
- Visible navigation between screens
- Form with more than four fields
- Multiple input types: text, date, select, number, textarea, checkbox
- Validation for required fields, minimum activity length, and budget range
- Data from the form appears on the Summary screen
- Responsive mobile-first interface
