# Review Rubric

Total: 100 points.

## 1. Core Functionality: 35 Points

- 10 points: at least three meaningful screens
- 8 points: navigation between screens works correctly
- 8 points: form has at least four useful fields
- 6 points: form data appears on another screen
- 3 points: app can be run from the submitted instructions

## 2. Validation and User Feedback: 15 Points

- 6 points: required fields are validated
- 5 points: at least one field has a specific validation rule
- 4 points: validation messages are clear and visible

## 3. Mobile Interface Quality: 15 Points

- 6 points: layout works on a phone-sized screen
- 4 points: controls are easy to tap
- 3 points: visual hierarchy is clear
- 2 points: text is readable and not cut off

## 4. Code Quality and Project Structure: 15 Points

- 5 points: project files are organized clearly
- 4 points: code names are understandable
- 3 points: repeated logic is handled reasonably
- 3 points: unnecessary generated files are excluded

## 5. Documentation and Submission Standard: 10 Points

- 4 points: student README is complete
- 3 points: screenshots are included
- 2 points: run instructions are correct
- 1 point: pull request and folder naming follow the standard

## 6. AI Usage Disclosure: 10 Points

- 4 points: AI tools used are named clearly
- 3 points: AI-assisted parts are described honestly
- 2 points: student explains what they verified or changed
- 1 point: unclear code or limitations are disclosed

## Possible Deductions

- Up to 20 points: project cannot run because required files are missing
- Up to 20 points: copied work without meaningful modification
- Up to 15 points: missing required screens, form, or navigation
- Up to 10 points: poor mobile usability
- Up to 10 points: missing or dishonest AI disclosure
- Up to 10 points: committed build outputs, dependencies, or unrelated files
- Up to 100 points: submission is not the student's own work
